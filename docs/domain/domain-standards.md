# Domain Standards — Media & Entertainment

Alignment mapping for this core. *Aligned to* throughout.

## Concept mapping

| Platform concept | Domain standard | Mapping |
|---|---|---|
| Masters & versions | SMPTE IMF (ST 2067) | Content registry follows IMF master/version thinking; essence stays in MAM systems |
| Metadata | IPTC | Catalogue metadata posture |
| Identifiers | EIDR | Registry codes at the boundary map to EIDR IDs in adopter systems |
| Rights | Licensing practice | Guarded licensed-units accounts; the no-overrun invariant |
| Distribution | DVB / ATSC | Transmission out of scope; this core records rights and schedules |

## Scope boundaries

No media essence storage, transcoding, DRM or playout: this is the content/rights/
schedule platform around certified media systems.
